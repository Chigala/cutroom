# Security

Please don't report security problems in public issues. Report them privately through GitHub instead:
**Security → Report a vulnerability** on this repository. You'll hear back as soon as possible, and
we'll credit you in the fix unless you'd rather we didn't.

Cutroom runs on your computer and works on your own files, so the most useful reports are about a
project folder, a graphic, a downloaded asset or an update that can make the app do something it
shouldn't.
